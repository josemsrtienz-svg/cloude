# Instrucciones del proyecto

## Usar siempre las skills
El usuario quiere que en este repo se usen **siempre** las skills disponibles:
- **roblox-game-creator** → diseño, GDD, core loop, economía, arquitectura Luau, QA, roadmap, /next-step.
- **crear-estructuraas-para-roblox** → diseño de mapas, zonas y estructuras.
- **detailed-3d-modeling** → modelos 3D (Blender) de memes, cañas, props (ver `V2MMW/Blender`).
- **artifact-design / dataviz** → páginas o gráficos para mostrar avances.
- **code-review / security-review / simplify** → antes de dar por terminado código.

## Juego actual
**Pesca de Memes** (nombre provisional). Docs:
- `docs/GAME_IDEAS.md` — investigación e ideas.
- `docs/GDD_PESCA_DE_MEMES.md` — diseño (fuente principal del estado del proyecto).

## Convenciones
- Roblox + Rojo + Luau. Idioma de comunicación: español.
- El servidor tiene la autoridad sobre capturas, monedas y datos.
- `MEME WARRIORS` (`src/`) y `V2MMW/` son proyectos anteriores: reutilizar sistemas copiándolos, no romperlos.
